## Plan

- `ui/daylight/daylight_route.dart`: one `DaylightPage` (a `Page` whose route builds the
  Daylight transitions), used by every `GoRoute` through `pageBuilder`.
  - push: shared axis (in from the trailing edge + fade; the old page drifts and dims),
    pop = the reverse. Tab destinations (Recall, Skills, You) and roots: fade-through.
    Mission: "through the door" arch reveal from the tapped door's rect (≤ 450 ms).
    Past result (the Dossier) and floor cleared: a 200 ms fade only.
  - Predictive back (Android 14+): the route's own transition scrubs with the gesture.
  - Reduced motion: 150 ms cross-fade.
- New `DaylightMotion` tokens (page, door, reduced page, ground fade, nudge, settle).
- Sheets: slide up with a slight overshoot, scrim fading in.
- Back controls: the top bar's leading tile nudges its icon 4 dp before acting; sheet close
  nudges down. `BackToExit` toast in Daylight.

## Done

- `DaylightMotion` tokens: `page` 300, `door` 450, `ground` 200, `reducedPage` 150, `nudge`
  (= blink 120), `settle` curve (≈3% overshoot). Brand tests cover them.
- `ui/daylight/daylight_route.dart`: `DaylightTransition` {push, through, door, ground},
  `DaylightPage` / `DaylightPageRoute` (own `PageRoute`; `delegatedTransition` tells the route
  below how to move; reduced motion read at push → 150 ms fade), `DaylightRouteMotion`,
