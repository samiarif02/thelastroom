## Decisions

- **Display font without the optical-size axis.** The opsz × wght variable file is 77 KB and
  held mobile performance at 95; the 600 instance is 22 KB and scores 97. The direction's web
  line says "Bricolage Grotesque 600"; headlines are a little wider than the mockups' opsz 96.
- **Nav order follows the page** (The panel, How it works, Scoring, Questions) so the highlight
  moves left to right as you scroll; the mockup listed "How it works" first.
- **The phone sits in the hero on a phone too** (mockup 09 had only Marcus): the demo is the
  product, and the CTA still sits in the first screen.
- **Proof is the evaluation, not testimonials**: there are no real player quotes yet.
- **The cast is a port, not shared data yet**: WS1's `cast.json` isn't on `main`; the README says
  to switch when it lands.
- Screens with `chrome-headless-shell` (same 145 build): Chrome for Testing's new headless mode
  hung on every screenshot on this machine today.
