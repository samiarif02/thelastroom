## Duolingo onboarding research (before building)

- **One question per screen, in a fixed order:** welcome (Duo waves) → language → how much you
  know → why you're learning → daily goal → notifications → first lesson or placement test.
  Sign-up comes last, after the player has used the core loop
  ([userguiding](https://userguiding.com/blog/duolingo-onboarding-ux),
  [junoschool](https://junoschool.pages.dev/article/duolingo-onboarding-experience/)).
- **Value before asking:** a real exercise runs before any commitment; the account is
  "delayed sign-up" ([goodux](https://goodux.appcues.com/blog/duolingo-user-onboarding),
  [appfuel](https://theappfuel-migrated.pages.dev/casestudies/three-learnings-from-duolingos-onboarding)).
- **Big tappable tiles, a progress bar at the top, the mascot asking in a speech bubble** and
  reacting to each answer; encouraging copy, small celebratory animations
  ([screensdesign](https://screensdesign.com/articles/duolingo-onboarding-design/)).
- **The goal is named tiers, not a number field:** Casual 5 min / Regular 10 / Serious 15 /
  Intense 20 ([duolingoguides](https://duolingoguides.com/how-to-change-daily-goals-on-duolingo/)).
- **Level question branches:** "first time" vs "I know some", and only the second gets the
  placement test (goodux above).
- **Length:** about 4 minutes in 2024 (7 in 2022), 20+ short screens; each screen is a tiny
  step so it feels fast (junoschool, screensdesign). Ours must be under 60 s, so fewer screens,
  same one-question rhythm.
- **The path home:** lessons as circles in order; done = gold and replayable, current = a
  bouncing START bubble, locked = grey and tapping says what unlocks it; a "Lesson complete!"
  reward with stat tiles after each lesson
  ([Duolingo blog](https://blog.duolingo.com/new-duolingo-home-screen-design)).

**What we borrow:** one question per screen with large tiles and a top progress bar; the
interviewer (Priya) asks in a line of subtitle and reacts in one line; the goal as named tiers;
skip on every step but the name; no account ask at all (silent guest, brief 05); the Tower as
the path (lit = done + score stamp, glowing "Enter" = START, dark + lock + teaser = locked,
tap a locked room says what opens it).
